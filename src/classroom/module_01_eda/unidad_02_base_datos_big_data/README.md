# Módulo 1 · Unidad 2 — Base de datos y Big Data

Material complementario construido a partir de la unidad **Base de datos y Big Data**, manteniendo intactos los contenidos existentes del repositorio.

## Propósito

Comprender cómo se conectan las **fuentes de datos**, los **tipos de datos**, los **roles profesionales**, los **modelos de servicio en la nube** y los **paradigmas fundamentales de Machine Learning** dentro de un flujo moderno de datos orientado a decisiones.

## Pregunta de decisión

> ¿Qué arquitectura, rol y paradigma analítico conviene elegir según el origen, el formato, la velocidad y el objetivo de los datos?

## Idea de cierre

**Fuente → tipo de dato → almacenamiento/plataforma → rol → paradigma analítico → decisión.**

La unidad no presenta tecnología como una lista aislada de herramientas: muestra cómo cada elección depende de la evidencia disponible y de la decisión que se quiere mejorar.
